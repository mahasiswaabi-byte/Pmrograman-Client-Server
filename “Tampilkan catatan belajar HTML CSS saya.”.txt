
CATATAN PEMBELAJARAN HTML DAN CSS

Catatan ini menjelaskan kode pada Interface.html, Visual.css, dan Login.js secara berurutan.
Istilah yang sudah dijelaskan sebelumnya, seperti padding, margin, display: flex,
justify-content, align-items, :hover, background-color, color, border-radius,
font-size, font-weight, font-family, @media, dan flex-wrap tidak dijelaskan ulang.

BAGIAN 1: PENJELASAN FILE Interface.html
==================================================

1. <!DOCTYPE html>
   Memberi tahu browser bahwa dokumen ini menggunakan standar HTML5. Baris ini
   bukan elemen yang tampil di halaman.

2. <html lang="en">
   Membuka elemen utama HTML. Semua isi halaman berada di dalam elemen ini.
   Atribut lang="en" memberi tahu browser bahwa bahasa dokumen adalah bahasa
   Inggris. Jika isi halaman berbahasa Indonesia, nilainya dapat diganti menjadi
   lang="id".

3. <head>
   Membuka bagian head. Isinya berisi informasi untuk browser, bukan isi utama
   yang ditampilkan kepada pengunjung.

4. <meta charset="UTF-8" />
   Menentukan jenis karakter yang digunakan dokumen. UTF-8 membantu browser
   menampilkan huruf, simbol, dan karakter bahasa Indonesia dengan benar.

5. <meta name="viewport" content="width=device-width, initial-scale=1.0" />
   Mengatur tampilan halaman pada perangkat berbeda. width=device-width membuat
   lebar halaman mengikuti lebar layar perangkat, sedangkan initial-scale=1.0
   mengatur tingkat zoom awal menjadi normal. Baris ini penting untuk tampilan
   responsif di tablet dan HP.

6. <title>Navbar Sederhana</title>
   Menentukan judul halaman yang biasanya terlihat pada tab browser, bukan di
   area isi halaman.

7. <link rel="stylesheet" href="Visual.css" />
   Menghubungkan file HTML dengan file CSS bernama Visual.css. Atribut rel
   menjelaskan bahwa file tersebut adalah stylesheet, sedangkan href berisi
   lokasi file CSS.

8. </head>
   Menutup bagian head.

9. <body>
   Membuka bagian body. Semua bagian yang ingin terlihat pada halaman browser
   diletakkan di dalam body.

10. <header class="header">
	Membuat bagian kepala halaman menggunakan elemen header. class="header"
	menghubungkan elemen ini dengan selector .header di file CSS.

11. <nav class="navbar">
	Membuat area navigasi. Elemen nav digunakan untuk kumpulan link menuju
	bagian atau halaman lain. Class navbar digunakan untuk mengatur tata letak
	navigasi melalui CSS.

12. <div class="logo">Arb.Wcite</div>
	Membuat wadah div untuk tulisan logo. Class logo memungkinkan tulisan ini
	diberi ukuran, warna, dan ketebalan khusus melalui CSS.

13. <ul class="nav-menu">
	Membuat daftar tidak berurutan untuk menu navigasi. Class nav-menu dipakai
	untuk mengatur daftar menu secara horizontal menggunakan CSS.

14. <li><a href="#">Menu</a></li>
	li adalah satu item daftar. a membuat link dengan tulisan Menu. Nilai href
	"#" adalah tujuan sementara yang mengarah ke bagian paling atas halaman.

15. <li><a href="#">Informasi</a></li>
	Membuat item menu bernama Informasi dengan pola yang sama seperti item Menu.

16. <li><a href="#">Perbaikan</a></li>
	Membuat item menu bernama Perbaikan.

17. <li><a href="#">Hubungi Kami</a></li>
	Membuat item menu bernama Hubungi Kami.

18. </ul>
	Menutup daftar menu.

19. <a href="#" class="nav-button">Login</a>
	Membuat link Login di luar daftar menu. Class nav-button membuat link ini
	terlihat seperti tombol melalui aturan CSS.

20. </nav>
	Menutup area navigasi.

21. </header>
	Menutup bagian header.

22. <main class="hero">
	Membuka isi utama halaman menggunakan elemen main. Class hero digunakan
	untuk mengatur posisi dan tinggi bagian utama melalui CSS.

23. <div class="hero-text">
	Membuat wadah untuk seluruh tulisan dan tombol pada bagian utama. Class
	hero-text mengatur lebar maksimum dan posisi teks.

24. <p class="label">Simple & Modern</p>
	Membuat paragraf pendek sebagai label. Class label memberi tampilan khusus
	seperti latar belakang, ukuran tulisan, dan sudut yang melengkung.

25. <h1>Navigation bar yang menarik dan mudah dipahami</h1>
	Membuat judul utama halaman. h1 biasanya digunakan satu kali sebagai judul
	paling penting dan memiliki ukuran tulisan paling besar.

26. <p>Contoh navbar sederhana hanya dengan HTML dan CSS</p>
	Membuat paragraf yang menjelaskan isi halaman. Tag p digunakan untuk teks
	biasa dalam bentuk paragraf.

27. <a href="#" class="hero-button">Lihat Dulu</a>
	Membuat link bertuliskan Lihat Dulu. Class hero-button membuat link ini
	memiliki tampilan seperti tombol.

28. </div>
	Menutup wadah hero-text.

29. </main>
	Menutup bagian isi utama halaman.

30. </body>
	Menutup seluruh isi yang tampil di browser.

31. </html>
	Menutup dokumen HTML.

BAGIAN 3: PENJELASAN FILE Login.js
==================================================

JavaScript digunakan untuk membuat halaman menjadi interaktif. HTML membuat
struktur halaman, CSS mengatur tampilannya, sedangkan JavaScript mengatur apa
yang terjadi ketika pengguna melakukan tindakan seperti menekan tombol.

1. const loginButton = document.getElementById("login-button");
   Membuat variabel tetap bernama loginButton dan mengambil elemen HTML dengan
   id="login-button". Variabel ini digunakan untuk mengakses tombol Login.

2. const loginModal = document.getElementById("login-modal");
   Mengambil elemen modal login berdasarkan id-nya. Modal adalah kotak login
   yang dapat ditampilkan atau disembunyikan.

3. const closeLoginButton = document.getElementById("close-login");
   Mengambil tombol X yang digunakan untuk menutup modal login.

4. const loginForm = document.getElementById("login-form");
   Mengambil elemen form login agar JavaScript dapat mengatur tindakan ketika
   form dikirim.

5. const passwordInput = document.getElementById("password");
   Mengambil input kata sandi. Elemen ini akan diubah tipenya ketika tombol
   mata ditekan.

6. const passwordToggle = document.getElementById("password-toggle");
   Mengambil tombol mata yang digunakan untuk menampilkan atau menyembunyikan
   kata sandi.

7. const loginMessage = document.getElementById("login-message");
   Mengambil paragraf pesan agar JavaScript dapat menampilkan informasi setelah
   form dikirim.

8. function openLoginModal(event) {
   Membuat fungsi bernama openLoginModal. Fungsi adalah kumpulan perintah yang
   dapat dijalankan ketika dibutuhkan. Parameter event berisi informasi tentang
   tindakan pengguna yang memicu fungsi.

9. event.preventDefault();
   Membatalkan tindakan bawaan link Login. Tanpa perintah ini, browser dapat
   berpindah ke alamat # sebelum modal ditampilkan.

10. loginModal.hidden = false;
	Menghapus keadaan tersembunyi dari modal sehingga kotak login terlihat.
	Atribut hidden pada HTML menentukan apakah elemen disembunyikan.

11. document.body.style.overflow = "hidden";
	Menghentikan scroll halaman ketika modal sedang terbuka agar perhatian
	pengguna tetap berada pada kotak login.

12. document.getElementById("username").focus();
	Memberi fokus langsung ke input Nama Pengguna sehingga pengguna dapat
	langsung mengetik tanpa mengeklik input tersebut.

13. function closeLoginModal() {
	Membuat fungsi untuk menutup modal login.

14. loginModal.hidden = true;
	Menyembunyikan modal login dengan memberi nilai true pada atribut hidden.

15. document.body.style.overflow = "";
	Mengembalikan pengaturan scroll body seperti semula setelah modal ditutup.

16. loginButton.addEventListener("click", openLoginModal);
	Menambahkan pendengar kejadian click pada tombol Login. Saat tombol ditekan,
	fungsi openLoginModal dijalankan.

17. closeLoginButton.addEventListener("click", closeLoginModal);
	Membuat tombol X menjalankan fungsi closeLoginModal ketika ditekan.

18. loginModal.addEventListener("click", (event) => { ... });
	Menambahkan fungsi tanpa nama yang dijalankan saat area modal diklik.
	Tanda => disebut arrow function dan merupakan cara singkat menulis fungsi.

19. if (event.target === loginModal) {
	Memeriksa apakah bagian yang diklik adalah area latar modal, bukan kotak
	login. Tanda === membandingkan nilai dan jenis data secara tepat.

20. closeLoginModal();
	Menutup modal jika pengguna mengeklik area di luar kotak login.

21. document.addEventListener("keydown", (event) => { ... });
	Mendengarkan tombol keyboard yang ditekan di seluruh dokumen.

22. if (event.key === "Escape" && !loginModal.hidden) {
	Memeriksa dua kondisi sekaligus: tombol yang ditekan adalah Escape dan modal
	sedang terlihat. Tanda && berarti kedua kondisi harus benar, sedangkan !
	berarti kebalikan dari nilai boolean.

23. passwordToggle.addEventListener("click", () => { ... });
	Menjalankan perintah ketika tombol mata ditekan.

24. const isPasswordHidden = passwordInput.type === "password";
	Menyimpan nilai true jika kata sandi sedang disembunyikan dengan tipe
	password. Input bertipe password menampilkan karakter sebagai simbol.

25. passwordInput.type = isPasswordHidden ? "text" : "password";
	Mengubah tipe input. Jika kata sandi tersembunyi, tipe diubah menjadi text
	agar terlihat. Jika sudah terlihat, tipe dikembalikan menjadi password.
	Tanda ? dan : disebut conditional operator atau ternary operator.

26. passwordToggle.setAttribute("aria-label", ...);
	Mengubah keterangan tombol untuk membantu pembaca layar mengetahui apakah
	tombol akan menampilkan atau menyembunyikan kata sandi.

27. passwordToggle.setAttribute("title", ...);
	Mengubah tulisan bantuan yang muncul ketika kursor diarahkan ke tombol mata.

28. loginForm.addEventListener("submit", (event) => { ... });
	Mendengarkan saat form dikirim, misalnya ketika tombol Masuk ditekan.

29. event.preventDefault();
	Mencegah form mengirim data dan memuat ulang halaman. Pada contoh ini,
	JavaScript hanya menampilkan pesan dan belum terhubung ke database.

30. loginMessage.textContent = "Data login siap diproses.";
	Mengubah isi teks paragraf pesan menggunakan textContent. Pesan ini memberi
	tahu pengguna bahwa data form sudah diterima oleh program.

==================================================
KONSEP JAVASCRIPT YANG DIGUNAKAN
==================================================

- const: membuat variabel yang tidak dapat diganti dengan nilai lain.
- document: mewakili dokumen HTML yang sedang dibuka di browser.
- getElementById: mencari elemen HTML berdasarkan nilai id.
- function: kumpulan perintah yang dapat dipanggil kembali.
- addEventListener: menunggu kejadian seperti click, keydown, atau submit.
- event: informasi tentang kejadian yang dilakukan pengguna.
- if: menjalankan perintah hanya jika kondisi tertentu benar.
- true dan false: nilai boolean yang berarti benar dan salah.
- hidden: atribut HTML untuk menyembunyikan atau menampilkan elemen.
- type="password": membuat karakter input kata sandi tampil sebagai simbol.
- type="text": membuat isi input tampil sebagai teks biasa.
- textContent: membaca atau mengubah teks di dalam elemen HTML.
- setAttribute: menambah atau mengubah atribut pada elemen HTML.
- focus(): menempatkan kursor aktif pada input tertentu.
- preventDefault(): membatalkan tindakan bawaan browser.
- ===: membandingkan nilai dan tipe data secara tepat.
- &&: operator logika yang berarti dan.
- !: operator logika yang membalik nilai true menjadi false atau sebaliknya.

RINGKASAN ALUR HALAMAN
==================================================

1. Browser membaca HTML dan mengenali dokumen sebagai HTML5.
2. Bagian head mengatur karakter, tampilan responsif, judul tab, dan file CSS.
3. Bagian body membuat header, navbar, logo, daftar menu, tombol Login, judul,
   keterangan, dan tombol Lihat Dulu.
4. CSS mengatur warna, jarak, ukuran tulisan, posisi, bentuk tombol, dan layout.
5. Media query mengubah navbar dan ukuran judul agar halaman tetap nyaman di
	layar tablet dan HP.
6. JavaScript membuka modal login ketika tombol Login ditekan.
7. CSS memberi efek blur pada area halaman di belakang modal dan menata kotak
	login di tengah layar.
8. JavaScript mengatur penutupan modal melalui tombol X, klik area luar, atau
	tombol Escape.
9. Tombol mata mengubah tipe input kata sandi antara password dan text.
