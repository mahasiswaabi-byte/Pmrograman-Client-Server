CATATAN PEMBELAJARAN HTML DAN CSS

Catatan ini menjelaskan kode pada Interface.html, Visual.css, dan Login.js secara berurutan.
Istilah yang sudah dijelaskan sebelumnya, seperti padding, margin, display: flex,
justify-content, align-items, :hover, background-color, color, border-radius,
font-size, font-weight, font-family, @media, dan flex-wrap tetap dipelajari dan
akan ditambahkan di bagian update baru agar lebih mudah dipahami.

==================================================
BAGIAN 1: PENJELASAN FILE Interface.html
==================================================

1. <!DOCTYPE html>
   Memberi tahu browser bahwa dokumen ini menggunakan standar HTML5.

2. <html lang="en">
   Membuka elemen utama HTML. Atribut lang="en" menunjukkan bahasa dokumen.

3. <head>
   Berisi informasi untuk browser, seperti meta tag dan title.

4. <meta charset="UTF-8" />
   Menentukan karakter yang digunakan agar teks tampil benar.

5. <meta name="viewport" content="width=device-width, initial-scale=1.0" />
   Membuat halaman responsif di layar tablet dan HP.

6. <title>Navbar Sederhana</title>
   Menentukan judul tab browser.

7. <link rel="stylesheet" href="Visual.css" />
   Menghubungkan HTML dengan file CSS.

8. <body>
   Tempat semua isi halaman yang terlihat.

9. <header class="header">
   Bagian atas halaman yang biasanya berisi logo dan navbar.

10. <nav class="navbar">
    Area navigasi pada website.

11. <div class="logo">Arb.Wcite</div>
    Kotak tulisan logo yang bisa diatur warna dan ukuran.

12. <ul class="nav-menu">
    Daftar menu navigasi.

13. <li><a href="#">Menu</a></li>
    Item menu yang dibuat seperti link.

14. <a href="#" class="nav-button">Login</a>
    Tombol login yang dibuat mirip link tapi diberi gaya CSS.

15. <main class="hero">
    Bagian utama halaman yang menampilkan konten utama.

16. <div class="hero-text">
    Wadah untuk teks dan tombol utama.

17. <p class="label">Simple & Modern</p>
    Label kecil yang biasanya digunakan sebagai judul kecil atau penanda gaya.

18. <h1>Navigation bar yang menarik dan mudah dipahami</h1>
    Judul utama halaman.

19. <p>Contoh navbar sederhana hanya dengan HTML dan CSS</p>
    Paragraf penjelasan halaman.

20. <a href="#" class="hero-button">Lihat Dulu</a>
    Tombol utama yang mengarahkan ke tindakan tertentu.

UPDATE BARU (2026-10-14)
==================================================

Ini adalah update tambahan agar catatan lebih mudah dipahami dan lebih singkat untuk belajar berulang-ulang.

1. padding
   Jarak di dalam elemen, antara isi dan batas elemen.
   Contoh: padding: 8px 12px;

2. margin
   Jarak di luar elemen.

3. display: flex
   Mengaktifkan Flexbox agar elemen tersusun rapi dalam satu baris atau kolom.

4. justify-content: space-between
   Memberi ruang di antara elemen secara horizontal.

5. align-items: center
   Menempatkan elemen di tengah secara vertikal.

6. :hover
   Efek saat kursor berada di atas elemen.
   Contoh: .nav-menu a:hover { color: #38bdf8; }

7. .label
   Selector untuk elemen dengan class="label".

8. background-color
   Mengatur warna latar belakang.

9. color
   Mengatur warna teks.

10. border-radius
    Membuat sudut elemen lebih bulat.

11. font-size
    Mengatur ukuran huruf.

12. font-weight: bold
    Membuat teks menjadi tebal.

13. font-family: Arial, sans-serif
    Mengatur jenis huruf utama dan cadangan.

14. @media (max-width: 768px)
    Aturan CSS khusus untuk layar kecil.

15. flex-wrap: wrap
    Memungkinkan item flex pindah ke baris berikutnya bila ruang tidak cukup.

16. Membuat logo pada navbar
    <img src="logo.png" alt="Logo" class="gambar-logo">
    lalu di CSS:
    .gambar-logo {
      width: 60px;
      height: 60px;
    }

17. Stroke tulisan
    -webkit-text-stroke: 1px #182053;
    Efek garis tepi pada teks agar lebih mencolok.

18. Struktur dasar navbar HTML
    <header class="header">
      <nav class="navbar">
        <div class="logo">Arb.Wcite</div>
        <ul class="nav-menu">
          <li><a href="#">Menu</a></li>
          <li><a href="#">Informasi</a></li>
          <li><a href="#">Perbaikan</a></li>
          <li><a href="#">Hubungi Kami</a></li>
        </ul>
        <a href="#" class="nav-button">Login</a>
      </nav>
    </header>

19. Struktur dasar hero section
    <main class="hero">
      <div class="hero-text">
        <p class="label">Simple & Modern</p>
        <h1>Navigation bar yang menarik dan mudah dipahami</h1>
        <p>Contoh navbar sederhana hanya dengan HTML dan CSS</p>
        <a href="#" class="hero-button">Lihat Dulu</a>
      </div>
    </main>

20. Tips penting
    - Gunakan margin dan padding agar layout tidak berantakan.
    - Gunakan Flexbox untuk penyusunan elemen yang rapi.
    - Gunakan media query agar tampilan bagus di desktop, tablet, dan HP.
    - Gunakan warna dan jarak yang konsisten agar desain lebih profesional.

Catatan tambahan:
HTML adalah struktur halaman, sedangkan CSS adalah desain dan tata letaknya.
Keduanya harus dipahami bersama agar website terlihat bagus dan mudah dibaca.

UPDATE RINGKAS 2026-10-14

Catatan singkat untuk mempermudah belajar:
- HTML = struktur halaman.
- CSS = tampilan dan tata letak halaman.
- Flexbox membantu menyusun elemen agar lebih rapi.
- Media query membuat tampilan responsif di HP dan tablet.
- padding = jarak di dalam elemen.
- margin = jarak di luar elemen.
- hover = efek saat mouse berada di atas elemen.

Belajar paling mudah dilakukan dengan melihat kode, lalu mencoba mengubah nilai seperti warna, ukuran, dan jarak sendiri.
